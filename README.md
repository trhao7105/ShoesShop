# 👟 Shoes Shop Web - User Guide

Tài liệu này mô tả cách sử dụng hệ thống website bán giày, bao gồm tài khoản khách hàng và quản trị viên.

# 🧑‍💻 1. Tài khoản khách hàng

## 🔐 Đăng ký tài khoản
- Người dùng có thể sử dụng chức năng **Register (Đăng ký)** để tạo tài khoản mới.

---

## 🔑 Đăng nhập
- Người dùng có thể đăng nhập bằng tài khoản đã tạo.

### 👉 Tài khoản mẫu:
- **Email:** `test@gmail.com`  
- **Mật khẩu:** `123456`

---

## 🏠 Giao diện người dùng
- Sau khi đăng nhập thành công, người dùng sẽ được chuyển đến **trang chủ (Home Page)**.
- Các chức năng chính:
  - Xem danh sách sản phẩm
  - Tìm kiếm giày
  - Xem chi tiết sản phẩm
  - Thêm vào giỏ hàng
  - Thanh toán
